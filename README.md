# Nify Trading Ltd. Website

This is the first website build for Nify Trading Ltd., based on the two supplied company/website instruction documents.

## Files

- `index.html` — complete single-page website
- `style.css` — responsive visual design
- `script.js` — mobile navigation, expandable careers cards and current year
- `assets/` — reserved for real Nify Trading photographs and future assets

## Run locally

The simplest option is to open `index.html` in a browser.

For a local development server (recommended), if Python is installed:

    python -m http.server 8000

Then open:

    http://localhost:8000

## Before publishing

Replace the photo placeholders with genuine Nify Trading / Freedom Mobile store photographs.

The supplied documents request approximately 8–12 genuine photographs and specifically prefer real business photographs over generic stock images.

Also confirm:
- Store-specific telephone numbers
- Store business hours
- Current promotions
- Genuine customer reviews / review-platform URL
- Final domain name
- Any approved logos/brand assets

No store-specific hours or direct store phone numbers were invented in this version; the supplied company document provides a general telephone number.
